# Галерея: разбор классики с govnokod.ru

При подготовке скилла просмотрено ~70 постов govnokod.ru на PHP, JavaScript,
C#, Java, Python, SQL, 1С и C (снимок — ноябрь 2026). Ниже 20 самых
показательных: что именно делает их смешными. Код сокращён и переписан под
учебный вид, оригиналы — по ссылкам.

Смысл галереи: смешное почти всегда строится на **одной** идее, доведённой
до конца. Ниже видно, какой именно.

---

### 1. Сезон года, который наступает дважды — #29236
```php
$current_month = date("m");
if ($current_month >= "03" && $current_month <= "05") $season = "spring";
elseif ($current_month >= "06" && $current_month <= "08") $season = "spring";
elseif ($current_month >= "09" && $current_month <= "11") $season = "autumn";
else $season = "winter";
```
Приём: **копипаста с не заменённым значением** + сравнение строк как чисел.
Почему смешно: лето существует, но называется весной, и никто не заметил.
Как повторить: возьми реальную бизнес-ветку и продублируй её без правки.

### 2. 200 строк ради одного `JOIN` — #28994
Хранимая процедура с восемью `OUT`-параметрами, логированием вызова,
`TRY/CATCH` и одним `SELECT TOP 1 *` в середине.
Приём: **ритуал вместо запроса**.
Как повторить: оберни действие из одной строки в 5 уровней «на инфраструктуру».

### 3. Токен в комментарии номенклатуры — #29287
```1c
Токен = НашиДанные.access_token;
НашТовар = Справочники.Номенклатура.НайтиПоКоду("01760").ПолучитьОбъект();
НашТовар.Комментарий = Токен;
НашТовар.Записать();
```
Приём: **хранилище секретов «где-то рядом»**.
Почему смешно: «временное» решение переживёт трёх интеграторов.

### 4. Пирамида `setTimeout` для клика по форме — #29243
```js
setTimeout(() => {
  jQuery(".btn-success").first().click();
  setTimeout(() => {
    // ... ещё шесть уровней, каждый по 200 мс
  }, 200);
}, 700);
```
Приём: **асинхронность через терпение**.
Как повторить: вместо `await` — фиксированные задержки с запасом.

### 5. Busy-wait как «фикс» гонки — #29175
```js
var token = 100000;
while (token != 0) { token = token - 1; }   // «добавил задержку — помогло»
```
Приём: **ожидание, которое жрёт CPU**.
Почему смешно: это официальный ответ на Stack Overflow, помеченный как fix.

### 6. Вся форма — конкатенацией строк — #29157
90 строк `formStr += '<div class="...">';`, потом `$('#modalForm').append(formStr)`.
Приём: **вёрстка как текст**.
Как повторить: HTML без шаблонизатора, с отступами из табов внутри строк.

### 7. Шесть `parentElement` подряд — #28979
```js
form = _this.parentElement.parentElement.parentElement.parentElement.parentElement.parentElement;
```
Приём: **DOM-навигация на ощупь**.
Как повторить: ни одного `querySelector`, только родители.

### 8. Одна строка на весь парсер — #29204
PHP-однострочник с `goto ___`, тернарниками-флагами и `define("_", [...])`.
Приём: **код-головоломка**.
Важно: в скилле такие вещи **не делаем** — читаемость и есть шутка.

### 9. `if` с точкой с запятой — #28985
```csharp
private void UpdateRowInfo()
{
    if (condition);
    {
        // код
    }
}
```
Приём: **пустой оператор + блок, который всегда выполняется**.
Почему смешно: баг искали днями, а `;` была серой на сером фоне.

### 10. `DateTime?` → `DateTime.Now` через исключение — #28939
```csharp
try { return (DateTime)date; }
catch { return DateTime.Now; }
```
Приём: **ошибка как значение по умолчанию**.
Как повторить: `catch` возвращает «примерно то, что имелось в виду».

### 11. 25 `case` вместо индекса — #28877
```csharp
switch (word) {
  case "11": Console.WriteLine(table[0,0]); break;
  case "12": Console.WriteLine(table[0,1]); break;
  // ... до "55"
}
```
Приём: **таблица, разложенная вручную**.
Как повторить: найди структуру, которую можно вычислить, и выпиши её.

### 12. `hashCode` из двух `int` через `new HashCode()` — #28809
```java
public int hashCode() {
    HashCode h = new HashCode();
    h.addValue(mFirst);
    h.addValue(mSecond);
    return h.hashCode();
}
```
Приём: **аллокация там, где нужны примитивы**.
Почему смешно: Netflix, продакшен, 2023 год.

### 13. Стримы для `String.join` — #29063
```java
if (!types.isEmpty() && types.size() > 1) return String.join(delimiter, types);
else if (types.size() == 1) return types.stream().findFirst().get();
return "";
```
Приём: **современный API ради самого API**.
Как повторить: замени одну строку четырьмя ветками и стримом.

### 14. Ожидание по расписанию — #29134
```python
def wait8s():
    wait5s()
    wait3s()

def wait10s():
    wait5s()
    wait5s()
```
Приём: **композиция из задержек**.
Почему смешно: `sleep(8)` запрещён архитектурой, арифметика — нет.

### 15. Восемь флагов вместо `set` — #29164
```python
has1 = has2 = ... = has8 = False
if last_dig == 1: has1 = True
elif last_dig == 2: has2 = True
# ...
```
Приём: **флаг на каждое значение**.
Как повторить: разверни множество в N переменных, добавь `== True`.

### 16. Переворот числа без `end` — #29163
```python
while n != 0:
    i += 1
    n = n // 10
while a != 0:
    last_digit = (a % 10) * 10 ** i
    total += last_digit
    i = i - 1
    a = a // 10
```
Приём: **два прохода, где нужен один**.
Как повторить: сначала посчитай длину, потом «умножай на 10 в степени».

### 17. Расстояние через побитовое ИЛИ — #29223
```sql
ORDER BY (|lng - :lng| + |lat - :lat|) ASC LIMIT 1
```
Приём: **«модуль» из другого языка**.
Почему смешно: псевдокод из статьи стал SQL, и заказчик это принял.

### 18. Захардкоженные даты — #28606
```sql
VALUE1 in (
  (extract(year from '2023-11-01'::date - interval '1 year')::varchar(4)||'-12-31')::date,
  (extract(year from '2022-11-01'::date - interval '1 year')::varchar(4)||'-12-31')::date
  -- ещё четыре строки
)
```
Приём: **дата, вычисленная вручную шесть раз**.
Как повторить: замени `generate_series` на список литералов.

### 19. Сортировка с `goto` и статическим буфером — #29288
```c
sorting:
    static char buf[128];
    memcpy(buf, a + size*d, size);
    // ...
```
Приём: **рекурсивная сортировка с меткой**.
Почему смешно: университетская лаба, которая «работает на тестах».

### 20. Сервер авторизации, который шутит — #29059
```csharp
Thread.Sleep(3600000);
if (today.Month == 4 && today.Day == 1) AcceptApplication();
else RejectApplication();
```
Приём: **календарная логика**.
Как повторить: `if (date == праздник)`, и пусть мир подстраивается.

## Что общего у всех двадцати

1. Автор был **уверен**, что делает правильно. Ни один не сомневался.
2. Ошибка **одна**, но проходит через весь код.
3. Код **запускается**. Иногда даже даёт правильный ответ.
4. Рядом нет ни одного человека, который сказал бы «а зачем?».

Именно поэтому жанр и жив: это не «плохой синтаксис», а **исчезнувшее
ревью**. Когда пишешь в этом режиме — воспроизводи не глупость, а
уверенность.
