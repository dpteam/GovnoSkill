# Диалекты говнокода по языкам

Один и тот же приём звучит по-разному. Ниже — «родные» болезни каждого языка:
то, во что он сам провоцирует человека без ревью.

Правило: бери 1–2 пункта из своего языка, а не весь список.

---

## PHP — родина жанра

Самый плодовитый язык govnokod.ru (5 700+ постов) и не случайно: он прощает всё.

- **HTML, PHP и SQL в одном файле.** Открыть `<?php`, закрыть `?>`, вставить
  таблицу, внутри `<?= $row['name'] ?>`.
- **Суперглобалы напрямую.** `$_GET['id']` в запросе, `$_POST` в вёрстке,
  `$_SERVER` в бизнес-логике.
- **`@` перед вызовом.** `@file_get_contents($url)` — «подавить всё, что
  пойдёт не так».
- **Магические `include`.** `include "db.php"` внутри цикла.
- **Строки вместо массивов.** `$data = "1|2|3"`, потом `explode`, потом
  забыли про `explode`.
- **Сезон по строке.**
  ```php
  $m = date("m");
  if ($m >= "03" && $m <= "05") $season = "spring";
  elseif ($m >= "06" && $m <= "08") $season = "spring"; // #29236
  ```
- **`==` вместо `===`** и наоборот — вперемешку, чтобы никто не догадался.
- **Функция `my_`/`real_`/`new_`.** `real_copy`, `new_parse`, `my_helper2`.

Вайб: «один файл — один сайт».

## JavaScript / TypeScript

- **Пирамида `setTimeout`.** Восемь вложенных колбэков по 200 мс, чтобы
  «дождаться загрузки» (#29243).
- **Busy-wait вместо `await`.**
  ```js
  let token = 100000;
  while (token != 0) token = token - 1;   // «добавил задержку, помогло»
  ```
- **Вёрстка строкой.** `formStr += '<div class="...">';` × 90 строк, потом
  `append`. Ищем форму полдня.
- **`parentElement` ×6.** `el.parentElement.parentElement.parentElement...`
- **`var` в 2026 году**, `==`, `!=`, `!!` — для надёжности.
- **TypeScript-типы-пустышки.**
  ```ts
  type int = number; type float = number; type double = number;
  ```
- **`any` как архитектура.** `const data: any = await res.json()`.
- **Глобальный `window.`** и функция `init()` на 900 строк.

Вайб: «работает в Chrome, остальное не наше».

## Python

- **Флаги `has1..has8`** вместо множества (#29164).
- **`while n > 0` для переворота числа** с `10 ** i` и `i -= 1`.
- **`wait1s`, `wait2s`, `wait5s`, `wait8s`**, где `wait8s` вызывает
  `wait5s` и `wait3s` (#29134).
- **`global`** в каждой третьей функции.
- **`except: pass`** и `except Exception: print(e)`.
- **Мутабельный дефолт** `def f(x, acc=[])`.
- **`input()` без проверок**, `int(input())` без `try`.
- **Свой велосипед** вместо `collections`: ручной `defaultdict`, ручная
  сортировка, ручной `deque`.
- **`print` как логгер**, `import *`, `from module import *` в трёх местах.

Вайб: «на лабе сдал — и хватит».

## Java

- **`getJoinedHeaderTypes`**: `if` на 2 элемента, `stream()` на 1 элемент,
  `return ""` в конце (#29063).
- **`new HashCode()` в `hashCode()`** (#28809).
- **`Integer == Integer`** и удивление на 128.
- **DTO на 40 полей** с геттерами, сеттерами и пустым конструктором.
- **`try/catch` на весь `main`**, `e.printStackTrace()`.
- **`String sql = "SELECT ... " + id`** — «потом переделаем на PreparedStatement».
- **Интерфейс + Impl + Factory** для одного класса.
- **`static` везде**, потому что «так проще вызывать».

Вайб: «паттерны прочитал, задачи — нет».

## C#

- **`if (condition); { ... }`** — пустой оператор (#28985).
- **`try { return (DateTime)date; } catch { return DateTime.Now; }`** (#28939).
- **`switch` на 25 `case`** вместо `table[i, j]` (#28877).
- **LINQ в LINQ в LINQ** с `.ToList()` после каждого шага.
- **`async void`**, `.Result`, `.Wait()` — и `Thread.Sleep` для надёжности.
- **`public static` God-класс** `Helper` на 4 000 строк.
- **Регион-простыня** `#region ... #endregion` вокруг всего файла.
- **`Console.WriteLine("хуй");`** — консольные шутки тоже жанр (#29272).

Вайб: «энтерпрайз начинается с `Manager`».

## C / C++

- **Свой `mod` через биты** (#29293), свой `pow`, свой `strlen`.
- **`goto sorting;`** посреди сортировки, `static char buf[128]` (#29288).
- **`scanf("%s", password)`** в массив на 16 байт (#29289).
- **`malloc` без `free`**, `free` дважды, `sizeof(pointer)`.
- **Макросы-макросы.** `#define BEGIN {`, `#define END }`.
- **`int` вместо `size_t`**, `-1` как «нет значения» в беззнаковом.
- **Своя реализация списка** на 300 строк, с утечкой в `remove`.

Вайб: «GCC не ругается — значит, правильно».

## SQL

- **Процедура на 200 строк** для одного `SELECT` с одним `JOIN` (#28994).
- **`SELECT *`** и `GROUP BY` на 30 колонок «на всякий случай».
- **Расстояние через `|lng - :lng|`** — побитовое ИЛИ вместо модуля (#29223).
- **`WHERE 1=1`** + конкатенация условий строками.
- **Захардкоженные даты** через `extract(year from ...) || '-12-31'` (#28606).
- **JOIN по диапазону** `price >= limit_1 AND price < limit_2` (#28804).
- **Имена `_Fld7941`, `_RRef`, `_Marked = 0x00`** — 1С-выгрузка в SQL (#28593).
- **`DISTINCT` как лекарство** от кривого `JOIN`.
- **Курсор вместо `UPDATE ... FROM`.**

Вайб: «база всё стерпит».

## Bash

- **`for f in $(ls)`** — пробелы в именах файлов станут сюрпризом.
- **`cat file | grep x | awk ...`** — `cat` для солидности.
- **Без кавычек**: `rm -rf $DIR/`, потом `DIR` пустой.
- **`cd` без проверки**, `set -e` не слышали.
- **Один скрипт на 800 строк**, `if [ ... ]` вперемешку с `[[ ... ]]`.
- **`echo` вместо `printf`**, цвета через `\033` руками.
- **`sudo` внутри скрипта**, запускаемого из cron.

Вайб: «у меня работало».

## Go

## Ruby / Haskell (для полноты)

## Как выбрать язык

Если пользователь не сказал — бери тот, что в проекте; если проект не
при чём — **PHP** (жанр) или **Python** (читается без подготовки).
Экзотику (Haskell, Assembler) не предлагай сам: сначала шутка, потом
демонстрация эрудиции.
